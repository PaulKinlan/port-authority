    Errors, crashes and browser warnings seen on this site

    Any page here that throws an error tells the server, with the browser's name and version. The browser also reports for itself, through the Reporting API, when a page crashes, when it blocks or slows something, and when a page uses a feature that is going away. Those are marked "browser report". That is how I find out that an experiment doesn't work in some browser.
