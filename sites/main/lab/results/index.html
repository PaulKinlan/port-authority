What browsers reported

Every browser that runs the lab sends back what it saw. This page adds those reports up by browser and version, and points at the tests where they disagree. The data is public as JSON: /lab/data/summary, /lab/data/reports, /lab/data/errors.

    Errors, crashes and browser warnings seen on this site

    Any page here that throws an error tells the server, with the browser's name. The browser also reports for itself, through the Reporting API, when a page crashes, when it blocks or slows something, and when a page uses a feature that is going away. Those are marked "browser report". This is how a browser where an experiment does not work shows up.
