Your accounts, and the sites that may use them.

Add an API key here once. When a site asks for an AI model, a window from this address opens and you choose which account it may use. The site gets a way to send prompts. It never gets the key. This is an experiment from Port Authority.

Try it without a key first: You can pick the built-in Practice model on any demo site below without adding an API key.

Experimental & local storage note: API keys added here are stored in plaintext in this browser's localStorage for this origin (never sent to the router's server). This is an experiment—if you test with a real provider key, use a low-limit or easily revocable key.
